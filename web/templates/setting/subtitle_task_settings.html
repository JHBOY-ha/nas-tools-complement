上传队列与空间
最多允许等待处理的上传批次数。队列满时拒绝新上传，请等待已有任务完成后重试。默认 10；范围 1–32。
单个 SRT、ASS 等文本字幕文件的大小上限。MiB 为文件容量单位，1 MiB = 1024 × 1024 字节。默认 20；范围 1–100。
一组 VobSub 字幕（.sub 与 .idx 两个文件）的合计大小上限，两个文件需成对上传。默认 200；范围 10–250。
一次上传所有字幕文件的合计大小上限，不得小于文本单文件或 VobSub 成对文件上限。默认 250；范围 20–250。
字幕任务暂存文件的总空间额度。至少为单批总量的 6 倍，为编码转换、临时文件和对齐参考留出空间。默认 2048；范围 256–4096。
暂存磁盘必须保留的可用空间。空间不足时拒绝新上传，避免任务耗尽磁盘。默认 1024；范围 256–51200。
一次上传允许的逻辑字幕数量；一组 .sub 与 .idx 成对文件算作一条字幕。默认 20；范围 1–20。
选择 LLM 对齐时，一次上传允许的字幕数量，不得超过普通单批字幕数量。默认 5；范围 1–5。
进程与任务预算
上传、修复和检测共享的 ffprobe、ffmpeg 或 LLM 重型操作并发上限。上传与检测各自串行执行；NAS 建议保持 1，减少磁盘与 CPU 压力。默认 1；范围 1–2。
单次 ffprobe 媒体或字幕探测的最长等待时间，超时后停止该次探测。默认 10；范围 3–60。
单次 ffmpeg 字幕处理的最长等待时间，超时后停止该次处理。默认 60；范围 10–600。
单条字幕进行 LLM 对齐的最长等待时间，避免响应缓慢的服务长期占用任务。默认 180；范围 30–900。
单个上传或修复任务的累计处理时间上限。任务恢复后继续累计，达到预算后停止处理。默认 60；范围 1–360。
检测与记录
一次检测允许处理的新增或发生变化的字幕数量上限，用于限制重复探测和磁盘读取量。默认 10000；范围 100–50000。
单次字幕检测的最长执行时间，达到上限后停止继续扫描。默认 60；范围 5–240。
深度目录扫描最多遍历的目录数量，避免大媒体库扫描长期占用磁盘。默认 50000；范围 1000–200000。
单次检测最多保存的问题明细数量，用于控制结果体积。默认 200；范围 20–1000。
已结束任务记录的保留天数，超期后由清理流程移除；不清理排队或运行中的任务。默认 7；范围 1–90。
最多保留的已结束任务记录数，超出后优先清理较旧记录；同时受保留天数限制。默认 100；范围 20–2000。
